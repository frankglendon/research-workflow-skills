# 从方法检索到页面安排的可复现示例

在仓库根运行 `python examples/knowledge/reproduce.py --output .runs/knowledge-demo`。输出本地索引、8 张原创卡、4 个检索试查和 `context.json`。示例不使用公司模板或历史客户内容，不调用模型或联网。

以商品价格比较为例：取回 `method-price` 后确定规格、国别、原币、日期和促销等采集字段；取回 `template-price` 后将这些字段组织成价格比较表，旁边写有证据的解释。样本数量不足时限定为“所采商品”，不能直接说某品牌整体更便宜。

这里展示方法如何帮助组织研究和选页型，不是已经完成的市场报告，也不代表已验证研究质量提升。真实项目仍需记录采用卡 ID、来源哈希和证据缺口，再取得并审阅当前市场资料。
