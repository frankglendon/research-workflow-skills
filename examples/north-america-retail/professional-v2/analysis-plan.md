# 分析口径与案头衔接

逐项指标、题号、分母、计算和限制见 codebook.xlsx 的「05 指标与分母」；这张表是分析交接规范。基础与加样独立报告，所有表展示未加权有效n、缺失、加权方法及排除规则。

1. 品牌漏斗：国家内基础样本计算无提示、认知、访问、6月购买、3月活跃、考虑和首选；基础总体购买率分母包括未认知者。B03/B02不能直接解释为门店成交率，B04/B03不能直接解释为个体复购率。
2. 品类与场景：从最近真实交易、用途、受礼对象和决策因素切分；跨国金额必须同币种、同税费，精确值与金额区间分开。线上面板品类购买者比例不是全人口渗透。
3. 品牌感知：仅认知且抽中该品牌者进入分母；记录抽取概率，对设计形成的不等概率与未出示作处理，不构造专有品牌资产分数。
4. NPS：100×（9–10分人数－0–6分人数）/有效0–10分人数；7–8分留在分母。基础和加样分别显示，同时报告无法评价率。触点评分只包含经历过该触点者；95未经历、97不知道等非实质选项按每题定义排除并单列，不能纳入量表均值或Top2分母。
5. 概念主张：主要指标为C03 Top2，美国为主检验市场，加拿大/墨西哥方向复核；在国家内随机分配，预先约定多重比较与缺失处理。n400/组约能识别10个百分点、n200/组约14点差异（设计近似，p=.5、双侧α=.05、80%功效，未作多重校正）；意向不能直接换销量。
6. 分群：需求与真实行为联合探索，再用训练/验证划分、稳定性与跨语言等值检查。不在没有实访数据时发布命名人群或占比。
7. 定性衔接：用真实案例修订问卷词语、IP/赠礼障碍及事前编码框架；保留反例，不以访谈提及次数推算市场份额。

案头报告含12份公开来源与20条事实断言。公司区域、报告期、币种与公开调查样本分别保留；没有同口径TAM、三国市场份额或客户经营数据，不发布这些数值。原始网页全文只保存在检索工作区，本案例提供原创分析、出处和定位哈希；离线复核不证明网页今天仍然有效。
