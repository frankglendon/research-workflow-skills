## 30-second introduction

The problem is deciding when an apparently reasonable AI result is ready to deliver. This project keeps reasoning in a host agent while code checks input identity, review coverage and Office file validity. Five skills share that boundary. A missing review, stale plan or fabricated excerpt blocks output. The public demo uses synthetic data and can be reproduced without model credentials.

## Two-minute demonstration

1. Run the demo and inspect its five outputs and summary.
2. Trace the chart's 100 and 140 values to two cells in the source workbook and a reviewed shape ID.
3. Show the QC source sheet next to the separate review sheet, including the uncertain verdict.
4. Run a fabricated-quote or missing-review test and show that no final output is created.
5. Finish with CI, the Microsoft validator, and the boundary between file correctness and semantic truth.
