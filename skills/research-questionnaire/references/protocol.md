# Plan protocol

The public schema and runnable fixtures are described in the repository `docs/protocols.md` and generated by `python -m research_skills demo --output .runs/demo`.

Every plan has `reviewed: true` and `review_sha256`, computed with `research_skills.contracts.fingerprint` over all fields except `review_sha256`. `input_sha256` contains the SHA-256 of input file bytes in CLI argument order. Complete the review before computing this digest.

Keep source documents and intermediate JSON in a local task directory, not `skills/` or `evals/`. Output files must use a new path.
