# 分析页型如何选择

| 要回答的问题 | 页面证据 | 分析要补什么 |
|---|---|---|
| 增长来自哪里 | 同口径趋势、数量与价格、渠道或地区拆分 | 基数、结构变化、无法归因的部分 |
| 为什么需求发生变化 | 行为/购买资料与行业表现对读 | 购买者和使用者、反例、相关与因果 |
| 竞争怎样争夺同一笔预算 | 购买任务 × 可核实商品与渠道比较 | 替代关系、客户实际可借鉴的机制 |
| 一个品牌的做法为何值得学 | 统一维度深挖，辅以产品/门店证据 | 动作到结果的证据强弱及资源差异 |
| 价格如何组织 | 指定商品的原币标价、规格及条件 | 入口款、主购款、升级款；不冒充全市场分布 |
| 国家之间有何不同 | 每国市场背景、当地玩家、商品和履约 | 何者可迁移、何者需本地调整 |
| 哪个机会优先 | 需求证据 × 供给缺口 × 客户适配 | 反证、行动条件、优先顺序的理由 |
| 到底回答了什么 | 开篇问题与证据结论一一对应 | 核心判断、支撑页、仍会改变判断的信息 |

页型服务论证，不要求每页三栏。比较表应保留相同维度；竞争定位图若没有测量数据就用分类描述，不能画伪精确评分雷达图。图表须保留单位、日期和地域。产品截图只证明其可见内容，销量、热度和购买偏好需要另外的证据。
