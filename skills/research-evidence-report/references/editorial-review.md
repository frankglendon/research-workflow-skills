# 案头成品的实质审阅

先读报告正文，再读质量记录。不要从“有来源、页数够、文件能打开”反推内容合格。

1. **商业答案**：逐条列出开篇问题、报告给出的答案、支撑页和剩余不确定性。若答案只是“后续问卷验证”，该问题尚未被案头研究回答。
2. **分析增量**：选一个核心机会追到事实，再检查替代解释和竞品反例。把客户名换成任意零售商仍成立的建议，应补到具体品类、场景、机制和约束。
3. **比较深度**：检查重点竞品是否用同一维度分析，国家差异是否来自当地证据。收入增长、品牌理念、官网入口不能互相充当可比绩效。
4. **内容构成**：统计实质分析、摘要、方法/未来研究和来源页。整体报告若大部分用于讲方法或下一步安排，应先补研究。比例只是诊断，不能以机械阈值替代判断。
5. **反证与忠实性**：标题有无把可能性写成确定事实；有没有证伪后仍保留的结论。客户表达保持专业中立，保留重要不利发现。
6. **页内与整册冗余**：同一数字反复出现应有新的用途，三段内容应有信息增量。删除口号、同义改写及反复强调“不能推断”的空页，把必要边界放到相关事实旁。
7. **成品表达**：看代表页与参考页的比较维度、证据颗粒度、图表作用和阅读负担。逐页看完整渲染，修正溢出和稀疏布局。原生图表与 SDK 0 errors 另记为文件质量。

评审记录应包含具体页面、问题、修正和修正后判断。禁止自封“凯度认证”或用 SkillOpt 的规则命中率替代真实报告评审。SkillOpt 优化时用完整案例或章节作输入，并保留薄弱初稿作负例，测试能否识别其缺乏研究答案；只测关键词或合规标签不足以评估此能力。
